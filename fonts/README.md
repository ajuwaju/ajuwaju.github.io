# Self-hosted fonts

All fonts here are served from this site; nothing is fetched from Google at view time.
Each is under the SIL Open Font License (see the LICENSE-*.txt files), which permits bundling.

- Instrument Serif (Regular, Italic) — headings and article titles
- DM Sans (variable, upright + italic) — body text
- Pinyon Script — the site name and script accents
- Silkscreen — pixel caps for tags
- Caveat (variable) — handwritten words and labels on the board

To swap one, drop the new file in and edit `../css/fonts.css`.
